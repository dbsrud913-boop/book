# 📚 하루 한 장 — 질문하는 독서 기록

하브루타처럼 책에 질문을 던지며 읽는 독서 기록 앱. 매일 마음에 남은 문장에서 나에게 던지는 질문을 만들고, 내 생각으로 답한 뒤 컬러 카드 이미지로 내보내 SNS에 공유할 수 있습니다.

## 주요 기능

- **오늘의 기록 (질문 독서 틀)**: ✏️ 오늘의 문장 · ❓ 나에게 묻다(질문) · 💡 나의 생각(대답) · 🌱 남은 질문
- **자동 계산**: 책별 N일째, 누적 기록일, 연속 기록(스트릭), 진행률(%)
- **책장**: 선반 위에 표지가 놓이는 책장 (읽는 중/완독/잠시 멈춤 그룹) — 표지가 없으면 파스텔 스파인 자동 생성
- **책 상세 페이지**: 함께한 기간(시작~마지막), 기록 횟수, 진행률, 총 독서 시간 + 그 책의 모든 기록·질문
- **이미지 카드 내보내기**: 파스텔 12색 테마 카드를 PNG(1080px급)로 저장
- **백업/복원**: JSON 파일로 내보내기·불러오기
- 로그인 없이 브라우저(localStorage)에 저장 — 모바일 브라우저에서 바로 사용 가능

## 개발

```bash
npm install
npm run dev          # 개발 서버
npm run build        # 프로덕션 빌드 (dist/)
npm run build:single # 공유용 단일 HTML 파일 빌드 (dist-single/)
```

## 기술 스택

- React 18 + TypeScript + Vite
- html-to-image (카드 PNG 내보내기)
- 저장소: localStorage (`src/storage.ts`에 격리 — 추후 Supabase로 교체 예정)
